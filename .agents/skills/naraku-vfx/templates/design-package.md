# VFX設計パッケージのテンプレート

新規・大きな作り直しでは `dev/design/<対象>/` に以下を作る。既存の設計があれば更新し、小さな調整は変更部分だけを記録する。記入のための架空の測定値や未実施の検証結果を作らない。

## DESIGN.md

- 対象・今回の範囲・現状の採用状態：
- ゲームの役割：通常／スキル／超必殺、命中時刻、範囲、ダメージ、継続、装填、連携。確認したコード：
- 実見したキャラ絵・既存技・比較映像：
- ユーザーの指摘／観察した事実／解釈：
- 前案の問題：輪郭、材質、奥行き、強弱、因果、消失。
- 一文のコンセプト：
- 主役／従属モチーフ／補助：
- 生成前の不採用条件：
- 時間構成：接触→ピーク→崩れ→残留→消失。戦闘上の命中との対応：
- 生成仕様：用途、視点、表示サイズ、余白、透過、レイヤ、参照と出典。
- 演出仕様：力の伝わり方、風・重さ、色と光、消失、実画面で落とす条件。

## README.md／引き継ぎ

コンセプト、各文書・原本・生成指示・出典へのリンク、採否の要点を残す。原画／実装／動画の品質／戦闘処理／実機性能／公開と通常採用の状態をそれぞれ記載する。実施していないものは未実施とする。次に確認する課題とユーザーの評価を残す。
