# ユズナミキ：標準工程の事例

2026-10-15時点。ユーザーが肯定したのは直近の設計・生成・自己レビューまでの流れ。新コンセプトの動画品質や通常採用の承認とは扱わない。

- 通常着弾は方向性への肯定。自然なコマ割り・配色・光量を優先するという指示。
- 次の狐火乱舞の炎候補は「地味で平面的」。滑らかな再生や戦闘処理の検証成功を、迫力の成功と混同しない。
- 花・花弁・火の水面という指定から作った開花候補は「花すぎて炎感がない」。花の種類・開き方が和風キャラから離れ、火の粉が一律に綺麗に散るという失敗。方向性への肯定を素材や動き全体への承認としない。
- キャラ絵の髪飾りと着物の桜を実見し「風にほどける、桜の気配を持つ狐火」を決定。火が主役、桜は一瞬の裂け目の連想、水面は短い接地反射。植物の花を燃やす表現へ戻さない。
- 原画第1案は範囲過大・白の面積・均等な火の粉で全体不採用。第2案は材質と局所の強弱を部分採用し、長い尾や亀裂状の床は除外。分離素材も大きな爆発全体を採用せず、用途別に部分採用した。
- 静止画では風や時間の自然さを確認できない。根元を保つ主炎→共通の風と慣性差を持つ火の粉→反射・煙→実戦場レビューの順に制作する仕様を残した。新仕様の動きは未実装。

根拠と成果は [設計パッケージ](../../../../dev/design/fox_fire_gust/README.md)、その中のDESIGN.md、REVIEW.md、MATERIAL_MAP.mdと生成指示を参照する。これらの狐火固有の形や秒数を他の技の正解にしない。

## 桜を強める追加評価

続くユーザー評価は「通常攻撃っぽい。桜の気配はもっと派手でもよい」。桜を常に最小限へ抑える正解に固定しない。火を主材質に、短い桜状の燃焼ピークと大きな燃焼片で通常攻撃との差を作る。最新判断は [改訂設計](../../../../dev/design/fox_fire_gust/SAKURA_REVISION.md)。範囲拡大は実際の最大段数とDPRを確認し、原画・アトラスだけでなく中間の合成解像度も検査する。
