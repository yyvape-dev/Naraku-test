## 毎回の生成に含めた指示

- 既存Naraku-testの通常敵の大きさ/画風を参照するが、原画は小さなゲーム表示サイズへ焼かず、本体400px以上の高精細にする。非ピクセルアート、細密な皮膚・布・金属。
- 1体だけの8コマ、4列×2段。最初4コマは前進、後ろ4コマは攻撃。正面固定カメラで顔・胸・腰が手前を向き、画面下へ進行。横向きを禁止。
- 左右の踏み出しと通過の4姿勢、攻撃は溜め→正面への打撃→振り抜き→戻り。5体目は歩かず浮遊の上下動/裾の変化、集光→両掌から正面へ放射→余韻→戻り。
- 体・武器・霊気をセル内に収め、透明背景と余白、同じ縮尺・足元アンカー・キャラの同一性を指定。
- 亡者は黄い遺物と錆びた刃、屍兵は赤い腕/鎖/大鉈、小鬼は長い角と鉤刃、鬼兵は緑の筋肉と双斧、浮遊霊は青緑の巻いた髪と裂けた長衣。
