# ボス4体＋サキュバス（エリート）

2026-10-17。ユーザー添付の5枚を参照し、GPT Imageで1体ずつ正面・高解像度の8コマを生成。サキュバスは顔の画風を維持しつつ、可愛い成人女性の顔/成熟した長身体型を指定した。攻撃の光が隣のコマにつながった初稿を再生成し、各コマが分離した最終版を保存。ユーザーの「サキュバスはエリートにしよう、実装して」により区分を確定。

PNG原本は各1536×1024、4列2段。上段は前進4、下段は攻撃4。毎回の生成指示に正面向き/画面手前への進行、既存ボス（source refH270/表示h160）参照、少し大きめで高頭身、個別高解像度、透明背景・全身/武器の余白を含めた。生成時の区分はgeneration-manifest.json、実装時は上表とENEMIESを優先。

`python3 dev/tools/pack_boss_enemies.py`で全身のalpha連結領域を分離し、武器を含む8コマを各640×640、アンカー(320,600)の1行アトラスへ配置する。画像の拡大/縮小/ポーズ合成/中割りはせず、原画の画素を保持する。前進の歩幅は控えめなコマがある。

既存の蠍の女王はh160/s127%。新ボス4体もs127%を使い、本体を約9〜15%大きく表示。サキュバスは既存エリートの鎚の大鬼h126/s100%に対して約13%大きい。顔と体の高頭身を保ち、攻撃のhitは各4コマの2番目。

配布WebPとJSONはdev/assets/。実ゲームで比較・停止・1/4速・時点指定はdev/mock/boss_enemies.html。ゲーム本体はNaraku-test。ソースとリンク方式配布indexの両方へ組み込む。
