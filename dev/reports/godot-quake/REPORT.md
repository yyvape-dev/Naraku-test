# GPT Image原画＋Godotの演出試作

主斬撃、命中、石片、砂煙の4透過原画と6段階の演出案をGPT Imageで生成。Godot 4.6.3で原画を動かし、方向ワイプ、短い破裂、石片の移動・回転、低い砂煙、ノイズによる消失を実装。36コマ40fps・床／空中2レイヤ。Godot透明ViewportのRGBをstraight alphaへ補正してWebPに格納。配布素材390,394bytes、復号後14,745,600bytes。

3シードで従来版と戦闘状態一致。0.1秒時点は命中待ち、0.2秒時点は2レイヤ生成。375×667と393×852で6時点描画確認、JavaScriptエラーなし。単独Chromiumで90フレームを測定し中央値16.7ms、p95約17.2ms。実機スマートフォンの性能測定ではない。

比較ページの左右モードと再生・停止を確認。通常ページは従来演出に復帰し、更新試作は`?quakefx=godot`のみ。以前の図形ベース試作は更新した。見た目の採用はユーザー確認待ち。
