# Godot大地割り試作

Godot 4.6.3、Xorg dummy display、Mesa llvmpipeのCompatibilityレンダラーで実際に透明Viewportを描画。床と空中の2レイヤ各36コマをPNG出力し、straight alpha補正、縮小・アトラス化してWebPへ。配布素材合計344,662 bytes、復号後14,745,600 bytes。

`godot_quake.py`成功。3シードで導入前後の戦闘状態が一致し、0.1秒時点は命中待ち・0.2秒時点は2レイヤ生成。2画面サイズで各6時点撮影、JavaScriptエラーなし。固定した2レイヤの描画を90フレーム測定し中央値16.6〜16.7ms、p95 17.4〜17.6ms。開発マシン上のChromiumであり実機の性能測定ではない。

比較ページの旧版／新版モード、再生・停止・スロー操作も確認。見た目の評価はユーザー確認待ち。全スキルへの展開は未実施。
