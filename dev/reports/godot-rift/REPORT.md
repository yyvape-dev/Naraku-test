# 乾坤一擲：縦に進行する赤黒い剣戟

手前から奥へ5段階の斬撃・隆起。専用GPT Image原画の尖った岩、飛散石片・粉塵、0.5秒周期の亀裂の脈動と画面の振動。3秒の地割れ効果と共に消える。Godot 4.6.3の実描画を75コマ25fps、床／空中2層に焼いた。配布1,693,962bytes、復号37,027,840bytes。

3シードで従来版と戦闘状態が一致。初撃の命中待ちと2層生成を確認。初撃90と3秒の継続ダメージ、鈍足、対象範囲は変更なし。超必殺は変更なし。表示の進行は初撃の判定タイミングとは独立。

比較ページで6時点の撮影、3秒での片付け、表示切替、時間指定、再生・停止を確認。JSエラーなし。375×667／393×852のChromiumフレーム中央値16.7／16.6ms、p95 19.6／20.5ms。物理端末の測定ではない。

?riftfx=godotのみで候補有効、通常ゲームは従来演出。比較ページdev/mock/rift_demo.html。
