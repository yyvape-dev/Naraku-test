# 乾坤一擲：連続した地面の傷跡へ作り直し

専用GPT Image原画rift_scar.pngを追加。深いジグザグの裂け目、両側の剥離・傾いた岩盤を一続きで描き、Godotで手前→奥へ不均等に開く。7区間の連続斬撃と亀裂から突き出す赤黒い光、飛散岩、薄い粉塵。岩の塊の反復を廃止し、地面を抉る形に変更。

75コマ25fps、床／空中2層、配布1,361,728bytes、復号37,027,840bytes。脈動と振動は0.5秒周期、2.52秒から消え、3秒で終了。

3シードで従来版と戦闘状態一致。初撃の命中待ちと2層生成を確認。初撃90、3秒の継続ダメージ・鈍足・判定範囲を維持。比較ページの6時点、時間指定、表示切替、再生・停止、3秒での片付けを確認。JSエラーなし。フレーム時間はchecks.json参照、Chromiumの測定で実機性能ではない。

?riftfx=godotのみ候補有効、通常ゲームは従来。比較dev/mock/rift_demo.html。
