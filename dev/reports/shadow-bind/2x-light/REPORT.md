# 影縫い：2倍速＋控えめな光

2026-10-16、ユーザーの追加指示。原画と通常採用の状態は前版から維持。

- 全54コマを60fpsへ変更し、見た目の長さを1.8秒→0.9秒へ。カード使用から命中までの0.16秒、15ダメージ、鈍足4.5秒、装填8秒は維持。
- 命中（約0.16秒）と帯が収束する瞬間（約0.39秒）に短い青紫の柔らかな光を追加。足元の光だまりと空中の小さなにじみ。帯の明るい芯のみ最大約16%強め、全画面フラッシュは加えない。
- 原画の黒い帯・輪郭・拡大時の透明度は維持。追加した光を含む床/空中の素材をGodotで再描画。
- Godot制作時間は30fpsのまま。source .32/.78秒がゲームの.16/.39秒になる。pack.pyとatlas.jsonには制作fpsと再生fpsを区別して記録。
- 光量の比較：最大に開くコマ27の空中・可視白画素は3,886→4,244（約9.2%増）。床の白画素は0のまま。light-measure.jsonに詳細。透明度を乗じたRGBで判定。数値そのものを品質の合格基準とはしない。
- 四辺alpha=0、レイヤ数・復号メモリは前版と同じ。配布4,104,762bytes、復号64,585,728bytes。
