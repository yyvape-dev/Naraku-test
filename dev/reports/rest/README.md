- 1枚目・2枚目：各45%。既存の体力+40%／狂気−20%を選択。
- 3枚目・4枚目：各5%。「うち捨てられた民家を見つけ、ゆっくり夜を過ごせた。」生存中の探索メンバーの体力100%・狂気0。精神崩壊からの蘇生は既存の教会ルールを維持。

- 既存の異変の挿絵UIを共用。画像は全体表示、縦の短い画面はスクロール。
- リンク方式でindex.htmlを再ビルド。追加画像1,465,122bytes。
