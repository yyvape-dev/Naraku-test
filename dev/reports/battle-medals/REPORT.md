# 左上メダル差し替え

5人の原画を512×512 WebPに縮小して登録。画像自体の再描画はしていません。円形のCSSクリップを使用し、元画像の四角い背景を除外します。画像内の金枠を活かし、従来の装飾枠はメダル登録者のみ非表示。HP赤・狂気紫のSVGコード描画を前面に維持。

外径48px（短い画面）／52px（長い画面）はbefore/after同じ。375×667では左5・上44、中心間隔53。画像窓は従来57%から66%へ変更（48px時31.68px、52px時34.32px）。

戦場before/after：375×667→375×537、390×664→390×530、393×659→393×524、393×852→393×695。各寸法は変化なし。戦闘ロジック変更なし。

4サイズで全5枚タッチ選択成功。剣士・狐・魔術師編成とシスター・蒼剣士・魔術師編成で5人全員の画像読み込み・表示確認。実機Safariは未確認。
