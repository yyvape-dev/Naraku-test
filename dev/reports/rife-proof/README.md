# RIFE v4.6 実行可否の確認

2026-10-16。ユーザーが提示したRIFE v4.6＋lavapipeの構成を、この環境で実際に確認。

- 公式配布：https://github.com/nihui/rife-ncnn-vulkan/releases/tag/20221029
- UbuntuリリースZIPから実行ファイルとrife-v4.6/flownet.{param,bin}だけをHTTP Rangeで取得（約12.9MB）。モデル全種を含む約431MBのZIP全体は取得していない。
- Mesa 25.0.7のlavapipeを/tmpへ展開。Vulkanデバイスは`llvmpipe (LLVM 19.1.7, 256 bits)`、PHYSICAL_DEVICE_TYPE_CPU。物理GPUなし。OSへパッケージをインストールしていない。
- モデル・実行環境は/tmp/naraku-rife。元のゲーム素材は変更なし。

## 実行した範囲

既存ラナ超必殺の36→37コマ（seq_lanaU_36/37）から、時点0.5の光画像（416×752）とアルファ用マスク（208×376）を実生成。マスクは元RGBAのAをグレースケールRGBへ展開して補間し、黒RGB＋補間アルファのRGBAへ戻した。RGBだけを変換すると元マスクは黒一色なので、必ずAを抽出する。

実測：光画像は初回10.227秒、ウォーム時2.412秒。実マスクは1.120秒。LP_NUM_THREADS=4、OMP_NUM_THREADS=4、-g 0、-j 1:1:1。48→96の全体処理時間は未測定。端コマ/ループをどう扱うかで、47区間の中間追加=95枚か、最後を追加して96枚かを明示する必要がある。

contact.pngは原画36／RIFE中間／単純な半透明混合／原画37。単純混合の二重像を減らせている一方、一部の岩の輪郭は柔らかくなるため「元コマと見分けがつかない品質」は保証しない。mask-composite.pngでRGBと補間アルファを合わせた状態も確認する。RGB/マスクを別推定する場合、境界のずれは別途確認が必要。

まだゲームへ採用・公開pushしていない。影しばり54コマを補間する場合も、演出の長さ0.9秒・ゲームの命中時刻を保ち、RGBとアルファ、メモリ増加、実画面を確認する。
