# 戦闘UI・4素材の組み込み（2026-10-14）

対象はNaraku-testのみ。ユーザー添付の下部全体・カード枠・ボタン枠・円形装飾枠を組み込んだ。円形中央のメダル画像は未提供のため、既存顔を仮置きして差し替え口を維持。

## 素材と配置

- 白背景の元JPEGを保存し、image_genで透過版を作成。外側とカード／円形枠の窓は透明、黒革の名札・ボタン中央は不透明。配布用は透過WebP（品質94）。
- 下部全体：ui_battle_tray_full.webp、1280×443、168754 bytes。下部全幅へ置き、右ボタンの外枠まで覆う。object-fit:contain・下寄せで紋章の縦横比を維持。旧9-slice台とSVG紋章は素材使用時に非表示。
- カード枠：ui_battle_card_frame.webp、720×1106、157066 bytes。戦闘札のみへ適用。カード絵の窓を上8%〜下24%に合わせ、名称は77.5%〜89.5%、種別は90%〜96.2%へ配置。文字は枠より前面。長い名称は帯幅に合わせて文字サイズを計算。通常／戦略は絵・モチーフ・文字色・種別で区別し、枠の金属色は共通。
- ボタン枠：ui_battle_button_frame.webp、320×383、47360 bytes。実際の押せる矩形40×38pxは維持。枠の見た目は横30px、上下・中央の3分割描画で紋章を保つ。右の一体枠の窓に合わせて配置。停止／再開はⅡ／▶、速度は×1／×2、読み上げ名・titleは日本語で保持。更新時に枠を消さない専用表示更新関数を使用。
- 円形枠：ui_battle_status_frame.webp、768×768、139058 bytes。表示外形48px（短い画面）／52px（長い画面）は維持。顔窓は外形の57%（48px時27.36px）で仮置き。ゲージはコード描画のまま、HP半径38／狂気34.5（100単位のSVG）、線幅3にして透明な環状領域へ合わせた。枠の紋章はゲージより前面。
- 中央のメダル差し替えファイル：ui_battle_face_<id>.webp。id=sword / fox / mage / sister / blue。正方形512px以上推奨。円形窓への配置・切り抜きは実装側で行う。現在は既存顔画像。
