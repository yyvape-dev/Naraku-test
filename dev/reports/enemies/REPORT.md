# 通常敵5体・正面高解像度版

2026-10-17。ユーザーの「実装して」、続く「画素数が粗い。進行方向も正面に」を反映。旧一括アトラスは公開前に停止し、5体を個別再生成した。原本と生成指示の要点はdev/art/enemies/README.md。

- 追加：遺物抱えの亡者、鎖肉の屍兵、鉤刃の小鬼、双斧の鬼兵、青衣の浮遊霊。すべて通常敵。
- 体と顔は正面で画面手前へ進む。1体8コマ、0〜3が前進、4〜7が攻撃。浮遊霊は前半と待機で浮遊する。
- 原画は各1536×1024/4×2、本体407〜514px。原画の画素を縮小せず切り出し、576×608セル×8の透過ロスレスWebPへ。refHを各体の実測本体高とし、ゲームの表示高70〜88へ描画時だけ合わせる。
- 既存の骸骨枠から亡者、獣枠から小鬼、騎士枠から屍兵/双斧鬼、呪術師枠から浮遊霊を抽選。出現番号のハッシュを使い、出現乱数の消費数を増やさない。能力値は各枠の既存敵と同じ。出現総数・大鬼/女王枠は維持。
- 近接の0.25秒命中に攻撃コマを同期。浮遊霊も0.25秒溜めて弾を放ち、以後の発射間隔は3.2秒。凍結で移動/浮遊/攻撃モーションを停止、鈍足で移動ループも減速。旧敵は従来6コマを使用。
- 調整パネル、突破後の残像、素材欠損時の6コマ仮絵も対応。敵の制作規則をAGENTS.mdへ継続指示として記録。
- 配布素材は7,638,076bytes、復号56,033,280bytes。index.htmlはリンク方式を維持。
