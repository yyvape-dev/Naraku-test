# 奈落の異変・酒場の噂：確定仕様

更新日：2026-10-17。対象：`yyvape-dev/Naraku-test`。実装確認基準：`f06667c`。

本書は導入後のユーザー修正まで反映した現行仕様。過去の `HANDOFF.md` にある「技ごとに物理／魔法を判定」「閉状態でも異変名と効果を常時表示」は取り消し済み。

## 遊びの流れ

1. 街で「酒場の噂を聞く」を開き、次の探索の異変を確認する。
2. 酒場で編成・装備を整える。これらの操作で異変は変わらない。
3. 出撃時に表示中の異変を探索へコピーする。1探索につき1つだけ。
4. 全戦闘・道中・中断再開を同じ異変で進める。
5. 帰還・踏破・全滅・精神崩壊で探索が終わると、次回分を抽選する。

新規開始時にも初回分を抽選する。直前と同じ異変は次の抽選候補から除外する。編成・装備・宿屋・階層変更・再読み込みでは引き直さない。

## 街の表示

- 初期状態は閉じる。見せるのは **酒場アイコン＋「酒場の噂を聞く」** の1行だけ。
- 酒場アイコンは既存 `UI.th_ic` の1番（CSS背景位置20%）を再利用する。
- 同じ行をタップして開閉する。閉状態の高さは約42 CSS px。
- 開いた本文に「次の探索」、異変名、具体的効果、噂文、固定ルール、属性説明、酒場へのボタンを表示する。
- 本文だけを最大30vhでスクロール可能にし、開閉する見出しを本文スクロールの外へ置く。
- 街の出撃パネルより上。絵がない街一覧にも表示する。
- 開閉時に `hubLayoutBottom()` で街背景の位置を調整する。
- 再開画面には保存中の異変名、戦闘開始の帯には有効な異変名を表示する。マップ歩数欄の `title` にも効果が入る（スマホで常設表示されるものではない）。

## 異変一覧

平穏を含め全8種。コードの定義は `dev/naraku_src.html` の `OMENS`。

|キー|名称|現行効果|
|---|---|---|
|`none`|平穏な奈落|変化なし|
|`swarm`|群れの夜|通常湧きの蓄積速度×1.25、大群の数を約1.25倍、通常敵HP×0.75、撃破ソウル×1.1|
|`giants`|巨影の気配|通常湧きの蓄積速度×0.75、大群の数を約0.75倍、通常敵HP×1.5・攻撃力×1.25、撃破ソウル×1.25|
|`whispers`|狂気の囁き|味方本人の現在狂気1%につき与ダメージ+0.5%。99%で+49.5%。精神崩壊は通常どおり|
|`undead`|不死者の行進|通常敵が致死ダメージを受けると、その場で一度だけHP35%で復活。「再起」を表示。報酬・撃破数は最終撃破時の1回だけ|
|`treasure`|宝物の匂い|分岐の宝箱抽選重み13→26、強敵13→23。敵撃破の金×1.2|
|`steel`|鋼の瘴気|敵が受ける物理ダメージ×0.7|
|`seal`|魔封じの霧|敵が受ける魔法ダメージ×0.7|

数の倍率は離散的な出現数／大群の丸めを含むため「約」。群れ・巨影による個体HP／攻撃力変更と復活はエリート・ボスには適用しない。エリート・ボスの予定出現時刻も変更しない。一方、撃破ソウル倍率・撃破金倍率・物理／魔法耐性はエリート・ボスにも適用する。

宝物の金は個体ごとに既存方式で整数丸め。宝箱内の金や踏破固定報酬は増やさない。マップの形・ノード数・接続構造を変更せず、分岐の種類の抽選重みを変える。巨影の攻撃力変更は個体の `e.d` へコピーして適用し、共有 `ENEMIES` を書き換えない。

## 物理／魔法の最終決定

**通常攻撃・スキル・超必殺・延焼・継続ゾーンは、すべて使い手のキャラ固有属性 `CHAR_TAG[who]` で統一する。技別の例外や上書きを追加しない。**

ユーザー理由：「スキルごとで物理魔法の判定つけるのはやめよう。ソウルカードも混乱する、強化がしづらい」。

|属性|キャラ|
|---|---|
|物理|ユズナミキ `fox`、ラナ `sword`、アベニウス `blue`、リンネ `ninja`、シオウ `samurai`|
|魔法|マリアンヌ `sister`、シェリ `mage`|

- ユズナミキの狐火・影縫い・百鬼狐火も物理。
- 物理キャラが付けた延焼は物理、魔法キャラの延焼は魔法。
- ラナの姫騎士衣装でも `sword` の物理属性を維持する。
- 武器の追加タグとソウルカードの適用条件は既存仕様のまま。武器タグが2つでも耐性を二重に掛けない。
- 持ち主のない禁忌「奈落の裁き」は中立。キャラ属性の耐性や本人狂気ボーナスを付けない。
- ダメージ補正は `hurt()` → `omenDamage(dmg, who)` の一箇所。発射時・延焼付与時・ゾーン生成時などで重ねて補正しない。
- `PHYS` 等のVFX用テーブルは見た目の制御であり、異変の属性判定に使わない。
- 回復量、凍結、鈍足、射程、効果範囲は異変の耐性では変更しない。

## 保存と抽選

セーブ形式は `v:1`、localStorageキーは既存の `naraku_save_v1` を維持する。

|場所|フィールド|役割|
|---|---|---|
|街 `S`|`omenSeed`|次回抽選に使う32bit種|
|街 `S`|`omen`|街で案内する次回分|
|探索 `R`|`anomaly`|出撃時に固定した異変|
|途中セーブ `S.run`|`anomaly`|再開用の写し|
|戦闘 `B` と設定 `BOPT`|`anomaly`|現在戦闘と巻き戻しで使う異変|

- `rollOmen(seed, runs, previous)` は独立したハッシュ抽選。戦闘・ドロップの乱数を消費しない。
- `beginRun()` が `S.omen` を `newRun()` へ渡し、`saveRun()` が保存する。
- 各ノード戦闘が `R.anomaly` を `BOPT` へ渡す。途中で街側の値を参照し直さない。
- 共通の `endRun()` で探索回数を増やして次回分を抽選し、保存する。
- `fixSave()`・`resumeRun()`・`showResume()` も保存異変を `genMap(seed, anomaly)` へ渡す。特に宝物では、異変を渡し忘れるとマスの種類が変わる。
- 新規抽選／旧セーブ移行は起動時にすぐ保存し、再読み込みで結果が変わらないようにする。
- 古い途中セーブはその探索だけ `none` で継続。終了後から次回抽選に入る。
- 古い街セーブは保存済みの探索回数・日数から決定的な種で移行する。不正な異変キーは `none` へ。
- 記録の写し（エクスポート／インポート）にも次回の異変と種が含まれる。

## 実装の入口

|対象|主な関数・場所|
|---|---|
|定義・抽選・属性補正・UI|`OMENS`, `omenKey`, `rollOmen`, `omenDamage`, `omenHTML`|
|敵能力／出現／復活／報酬|`spawn`, `spawner`, `hurt`|
|マップの種類|`genMap`|
|保存移行・途中保存|`newSave`, `fixSave`, `saveRun`|
|探索開始・終了・再開|`beginRun`, `newRun`, `startNodeBattle`, `endRun`, `resumeRun`|
|街の告知|`hubBuild`, `hubSync`, `VIEWS.townPlain`, `.omen-notice`, `.omen-body`|

すべて `dev/naraku_src.html` 内。配布 `index.html` を直接編集せず、ソースを変更してリンク方式で再ビルドする。

## 確認用API

本物のセーブを触らない新しいブラウザーコンテキストで使う。

```js
// 単発戦闘。異変を省略すると従来どおりnone。
NARAKU.start(['fox', 'sword', 'mage'], 3, {anomaly: 'steel'});

// 検証用の新規探索。第4引数が異変。
NARAKU.startRun(['fox', 'sword', 'mage'], 123, 1, 'treasure');

// 街の告知表示を確認。freshは検証用なので既定none、自動保存も切る。
NARAKU.fresh();
NARAKU.S.omen = 'steel';
NARAKU.town.show();
```

`NARAKU.fresh()`／`startRun()` の既定noneは検証条件を維持するため。製品の街出撃が常に平穏という意味ではない。通常出撃は `NARAKU.sortie()`／画面の出撃ボタンで表示中の異変を引き継ぐ。

検証コマンド・証跡の更新状況は [Claude引き継ぎ書](CLAUDE_HANDOFF.md) を参照。
