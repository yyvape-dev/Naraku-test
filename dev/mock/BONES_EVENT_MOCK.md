# 骸の山：UIモック

実ゲームへ接続する前の画面比較用。ゲーム本体・報酬抽選・保存には変更を加えていません。

## 開き方

- A案（画像全幅4:3）：`bones_event_mock.html?layout=full`
- B案（画像を少し小さく）：`bones_event_mock.html?layout=compact`
- 敵に見つかった結果：上記URLに `&outcome=ambush` を追加。

本文・選択肢・注意書き・結果の文章は、既存の `EVENTS` の `id: bones` から使用しています。
選ぶ前は進行ボタンを出さず、画像→イベント名と説明→2つの選択肢の順に積みます。長い内容はスクロールできます。
選択後は選択肢を結果と進行ボタンに置き換えます。大きな空白を挟みません。

## 操作

「荷を漁る」では成功の表示例（金+90・装備1点）、`outcome=ambush` の場合は敵に見つかる表示例（金+40・迎え撃つ）を確認できます。
「立ち去る」は既存の通過文章を表示します。
進行ボタンを押すと比較用の選択画面に戻ります。実際の探索・戦闘へ移動せず、保存・報酬付与・抽選は行いません。

## 画像

添付画像を `assets/event_bones.webp` にWebP品質90で配置。1280×960px、420326 bytes。
どちらの案も縦横比を維持し、トリミングしません。
モック専用の素材なので、ゲームの埋め込み対象 `dev/assets/` には配置していません。

## 検証

390×844、375×667の両サイズでA・Bを表示して撮影。
画像・既存の本文・2つの選択肢・成功／通過／敵襲結果・進行ボタン・画像エラー時の操作停止を確認。
正常操作時にJavaScript／コンソールエラーなし。localStorageへ書き込みません。
