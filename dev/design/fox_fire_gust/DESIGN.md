# 狐火乱舞：デザインレビューから制作へ（2026-10-15）

## 結論とコンセプト

**風にほどける、桜の気配を持つ狐火。** 主役は燃焼する火。桜は輪郭が裂ける瞬間の連想、火の水面は発生点と短い反射として従属させる。実物の花が咲いて散る技にはしない。

この文書は、ゲームデザイン上の役割→キャラクターとの接続→前案の失敗要因→原画の生成・自己レビュー→動きと光と風の制作仕様を一本に結ぶ。生成した原画は構図の検討資料であり、実装映像や品質達成の証明ではない。ゲームコード・標準演出の採用状態は今回変更しない。

## 1. ゲームデザイン上の役割

確認元：dev/naraku_src.htmlのCHARS.fox／CARDS.fox_fire／useCard／impact。

- ユズナミキは速射単体の軽快なキャラクター。通常攻撃は基礎8ダメージ・0.42秒周期。狐火乱舞はそこに挟む短い範囲攻撃。
- 狐火乱舞は55ダメージ・半径72・使用から0.16秒で一度命中・基礎装填5秒。持続する攻撃領域ではない。二重詠唱は既存の別命中。
- 見せたい判断は「ここへ範囲攻撃が当たった」「このキャラの狐火だ」「攻撃はもう終わっている」。長く立つ花や池、繰り返す噴出は設置技・継続ダメージの誤読を招く。
- 超必殺の百鬼狐火は画面全体に多数の花と水面を見せられる。通常スキルにその景色を縮小移植すると、短い一撃の役割と強弱の序列が崩れる。

**設計判断：** .16秒の着火を最も明確な衝撃にし、その直後の短い火の広がりが視覚的ピークになる。敵の頭・武器の動きを読む空隙を保つが、根元の密度とピークの勢いは削らない。残留は薄く短い。

## 2. キャラクターから拾うもの

実見：dev/cardart/src_fox.webp、guide_fox_throw.png、fox_ult_seq/08・20・36.webp。

- 髪飾りと着物の桜、赤黒と暖色の金、狐耳、短い衣装、身軽な投擲の動き。
- 狐火には人為的に操る軌道がありつつ、燃焼する先端や火の粉は制御しきらない。この「操る根元／風にほどける先端」の差で妖しさを作る。
- 花の選択を「和風の花だから」で済ませない。今回は実際の衣装の桜へ結びつける。桜の模型・桜アイコン・常に整った五弁の輪郭は作らない。
- 百鬼狐火からは赤い火の水面と散る花の気配を継承する。蓮状の大きな花冠と荘厳な開花動作をそのまま通常スキルの主役にしない。

## 4. 原画生成の目的と落とす基準

生成物は、同じ敵・同じ地面・同じカメラの3段階の演出原画。命中／ピーク／余韻の因果、面積、色、前後関係を確認する。ラベルのない3コマから動きの品質を証明しない。

優先順は **火の材質と勢い → 風と奥行き → 和風の桜の気配 → 水面の余韻**。

次は自己レビューで不採用または要修正とする：

1. 縮小時に最初に「花」「赤い布」「リボン」と読める。
2. 中心から同じ形・同じ高さ・同じ間隔で伸びる。閉じた花冠・完全な円環が残る。
3. 火の粉が均等な放射、均等な渦、背景全面のラメとなる。
4. 根元も先端も同じ厚み・同じ色・同じ光量で、熱の勾配が読めない。
5. ピークでも余韻でも同じ面積・同じ密度。常設の池や植物が残る。
6. 敵を描き替えて成立させる、攻撃面積を大幅に広げるなど、実ゲームの条件から逃げる。

自己レビュー結果・生成物の採否・修正理由はREVIEW.mdに別記する。完成原画をそのまま貼って動かすことはしない。

## 6. 動き・風・材質の制作仕様

### 主炎

- 2つの不揃いな着火点を原因にして、3つの異なる大きさの燃焼塊を作る。同じ花弁を等角度に並べない。
- 曲面は奥行きを支えるために使い、形を固定する花弁の骨格にしない。先端は炎のアルファ形状・UV移流・首の細まり・輪郭浸食で絶えず分離する。
- 主炎の移流にも粒子と同じ風速場を使い、粒子だけが別方向へ飛ぶ状態を防ぐ。
- 粗い大きな揺れで根元の向きを保ち、細かい速い揺れは先端だけ強める。全体を均一なノイズでぐにゃぐにゃさせない。
- 桜の丸い裂片・小さな切れ込みは、火の形を分断する短い局面にだけ使う。五弁形が見えても保持上限は設計上約50ms。実装後の連続画像で確認する。

### 風と火の粉

共通の風速場に、各粒子が異なる速さで追従する。乱数だけで自然に見せようとしない。

`加速度 = 浮力 + 抗力係数 × (その場所・その時刻の風速 − 粒子速度) + 局所の渦 − 重い粒子の重力`

- 支配的な突風はひとつ。画面の例では左手前→右奥。投擲方向の初動と背景の風を分け、命中点を風下へ移動させない。
- 風は常に一定ではない。.22–.36秒で強まり、遅れて弱まる。位置によって流速と渦が異なる。
- 軽い小火の粉は高い抗力（目安5–12/秒）で風へ素早く追従。重い燃えかすは低い抗力（目安2–4/秒）で初速が残り、低く遅れる。
- 根元ごとに短い群発と休止を作り、群の中も発生時刻・寿命・質量を変える。同じ円周上へ固定数を等分しない。
- 一部が局所渦で横へ巻き戻るが、全粒子が同じ螺旋を描かない。粒子の数より、塊と空白、軌道の違いを優先。
- 減光は燃え尽きる熱量に対応させる。白桃→橙朱→暗赤→消失。全員同じ寿命・点滅・終点にしない。

### 光・水面・煙

- 強い光は命中の根元に限定。白い芯の面積は設計目標として炎の発光面積の約10%以下、保持も短くする。暗部と暖色中間調を潰さない。
- 地面と敵への局所の暖色反射を短く連動させる。全画面の白フラッシュ・周期的な明滅・全体の一様な加算は使わない。
- 火の水面は既存の液体素材を細い接地反射へ再利用できる。0.2–0.6秒の局所のうねりと遅れた反射に絞り、花を支える常設の池を描かない。
- Jettelly／KenneyのCC0煙は、ごく少量の密度の補助や形状マスクに使える。火の輪郭とピークの面積を煙へ明け渡さない。使用時は既存ライセンスと素材名を引き続き記録する。

## 7. 制作順序と評価責任

1. このコンセプトと上の落とす基準で、生成した演出原画をこちらでレビュー。良い部分と直す部分を分け、部分採用も明示する。
2. 採用した火の形だけを根元・奥の立ち上がり・手前の低い炎・燃え落ちる裂片へ分けて素材制作。完成した花の絵は制作しない。
3. 最初は主炎だけで.16–.68秒の勢いと切れ方を作る。風の方向が読めなければ粒子や光で隠さず直す。
4. 同じ風速場で火の粉を足し、抗力と質量差を検証。その後に水面の反射と少量の煙。
5. 実際の敵と床で、ピークの密度・色・視認性と終わり方を自己レビュー。原画との乖離と理由を記録する。
6. 等速・スロー・コマ送りと30秒リピートで比較。ダメージ等の戦闘一致・寿命・未読込フォールバック・小画面の描画も別に検証する。

原画が良い／コマが滑らか／ゲームが動く／炎として魅力がある、を別の判定として扱う。ユーザーへ未整理の試作を出し続けて品質判断を委ねない。
