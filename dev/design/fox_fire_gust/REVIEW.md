# 生成物の自己レビューと採否

判定基準は生成前にDESIGN.mdの4節へ固定。ここでは画像で見えることと、動きで未検証のことを区別する。モデルが生成指示へ従ったと推定して採点しない。

## 第1案：部分採用、全体は不採用

生成：generated/01_direction_board.png。指示：prompts/01_direction_board.txt。ゲーム画面とキャラクター絵を参照した演出原画。実ゲームのスクリーンショットではない。

| 基準 | 実見した内容 | 判断 |
|---|---|---|
| 火が第一印象か | 熱い根元、薄く裂ける端、燃焼する胴があり、前の厚い花弁より火として読める | 火の材質・輪郭の一部を採用 |
| キャラの桜の抽象化 | 完成した植物を立てず、炎の裂け方へ寄せられている。ただし固有性はまだ弱い | 桜の模型へ戻さず、短い裂片の形へ限定 |
| 範囲技として適切か | 中央のピークが左下から右上を横断する長い帯になり、足跡が大きすぎる | 全体構図は不採用。半径72の局所へ戻す |
| 時間の強弱 | 左にも既に大きな炎があり、命中からピークの差が小さい | 左を短く密な着火へ。中央だけ面積と高さが一段上がる |
| 配色と光量 | 白黄の発光面が広く、赤朱の中間調が明るい面に負ける | 全体を暗くせず、白い芯だけ狭める |
| 風と火の粉 | 右の尾は風向きを示すが、複数の長い平行の流線と均等な粒に寄っている | 塊と空白、軽重の遅れ、局所の巻き戻りを再指示 |
| 実ゲーム条件 | 背景・敵を参照しているが、画像生成による描き直しがある | 構図検討にのみ使用。戦場への実装品質の証明にしない |

### 修正指示

足跡を敵の身長約2.4倍の直径、炎の最高点を敵の身長程度に抑える。根元は命中点に固定。風は火の先端と火の粉を曲げ、攻撃の中心を移動させない。第1案を動かす作業には進まず、修正原画を生成する。

## 動きでしか判定できない項目

- 火の首が細まり、切れ、燃え尽きる順序。
- 火の粉が抗力と質量の違いで同じ風へ異なる速さで追従すること。
- 桜を連想する形が約50msを超えて固定されないこと。
- .16秒命中の鋭さと、その後の減衰が一撃として読めること。
- コマ補間の二重像、明るさの中間落ち、実際のスマホでの画面密度と性能。

これらは演出原画の見た目だけで合格にしない。実装・動画はまだ新コンセプトで制作していない。

## 第2案：方向・一部形状を採用、未修正部分は制作へ持ち込まない

生成：generated/02_direction_board.png。指示：prompts/02_revision.txt。第1案を参照して再生成。

| 基準 | 第2案で実際に見えること | 制作への採否 |
|---|---|---|
| 初動とピークの差 | 左の着火が小さくなり、中央で炎が増してから右で主炎が減る | この強弱を採用。秒数と速度は未検証 |
| 火の材質 | 花弁の厚い面ではなく、細い根元・熱い胴・千切れた端と隙間がある | 素材の核として採用 |
| 足跡と高さ | 第1案の大きな斜めの帯から対象の近くへ縮まった。ただし中央の奥の大きな巻き上がりはまだ強い | 構図は参考。実装時の足跡は半径72から計算し、原画の大きさをそのまま採らない |
| 光量 | 第1案より白い面が減ったが、中央は依然白黄が強い | 素材生成では暖色中間調と狭い芯へ分ける。原画全体を加算しない |
| 風と火の粉 | 右に塊と空白は増えたが、遠い右上に長い火の尾が残る | 方向と塊の考え方は採用。長い尾は不採用。火の粉と短い燃え落ちる裂片へ置換 |
| 地面の表現 | 右の地面に赤い筋があり、亀裂・継続する傷跡にも読める | 不採用。短い水面の反射に限定し、地面が割れる形を生成・実装しない |
| 桜と和風 | 植物の形へ戻っていない。一方、桜の固有性が強く読めるとはまだ言えない | ここは未達・動きで検証。桜の記号や花冠を足して安易に解決しない |

### 生成素材へ渡した内容

第2案全体を完成素材として切り抜かず、採った火の材質だけを参照し、根元・奥の炎・手前の低い炎・燃え落ちる裂片を独立した透過素材として生成する。地面の筋、長い尾、敵の描き直しは素材へ渡さない。

**現時点の達成：** ゲーム内の役割、キャラとの接続、主従、生成物の採否、風と光と時間の仕様を一本に決めた。新コンセプトの動画品質やゲーム実装の達成を主張していない。

## 分離素材のレビュー

generated/03_source_materials.pngを実見。素材ごとの採否と動きの対応はMATERIAL_MAP.md。

- 火としての読みに使える部分は、奥の炎・手前の低い炎・燃焼する裂片。
- 初動の素材は大きい一般的爆発の形が強く、全体は不採用。中央の密度に用途を限定する。
- 等分セルからはみ出す部分があるため、自動2×2分割は不採用。個々の可視範囲の確認が必要。
- 桜の気配・風の自然さ・一撃のテンポは、このシートから達成済みとは判定しない。

新コンセプトでは、前の植物の開閉アニメーションや、等角度散会の粒子運動をそのまま流用しない。
