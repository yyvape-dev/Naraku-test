## 何が違うか

- 原画はCodex版と同じGPT Image 4枚（`../quake/art`）と6段階の演出案。見た目の設計は変えず、動かし方だけを変えた。
- タイミング表（t=0がダメージの瞬間なので予兆なし）
  - 0〜0.05秒 斬撃が対角に走る。先端を白く焼く
  - 0.035〜0.12秒 炸裂（ease-out expo）、芯の閃光、光の筋
  - 0.045〜0.6秒 岩が放物線で飛ぶ。地面の影、速い間の残像、熱で光る縁が冷える
  - 0.03〜0.88秒 枝分かれした地割れが外へ走り、白→橙→赤→黒と冷える
  - 0.07〜0.88秒 砂煙が地面を這って広がり、ノイズで崩れて消える
  - GPU粒子：火花110（0.045秒に一斉）・残り火46（乱流で上昇）・黒い煤26（割れ目から立ちのぼる）
- 各層を2回焼く：光（黒地・加算・**2D HDR＋WorldEnvironmentの発光**）と、抜き（透明地・通常合成）。`pack.py` が光の最大値を不透明度にして抜きの上に重ねる。
  - 2D HDRをオンにすると透明背景が効かなくなるので、HDRは光の回だけオンにする（`animate()` 内）。
- 出力はゲームの既存形式と同じ（6×6、床192px・空中256px、36コマ40fps、アンカー0.5/0.5625）。`out/claude_quake_*.webp` を `dev/assets/vfx_quake_floor.webp` / `vfx_quake_air.webp` に差し替えれば `?quakefx=godot` でそのまま映る（未実施）。
- 重さ：配布 約795KB（2層）、展開後 約14MB（Codex版と同じ）。

## 焼き方

```sh
sh dev/godot/quake_bloom/bake.sh     # Godot 4.4.1が無ければ自動で取得。xvfb-run と Pillow/numpy が必要
```

## 光量を調整するつまみ（`quake.gd` の `_ready`）

|つまみ|今の値|効き方|
|---|---|---|
|`light.modulate`|1.12|光全体の明るさ。上げるほど発光する範囲が広がる|
|`CLIMAX_HEAT`（定数）|0.36|炸裂の熱。1＝白熱、0＝深紅。2026-10-15「炸裂を赤黒く、白を半分に」で1→0.36（白い画素 13,093→6,437、49%）|
|`s_slash` / `s_impact` の `self_modulate`|赤寄り（0.8,0.5,0.42）/（0.8,0.42,0.34）|炸裂の色味と明るさ|
|`env.glow_intensity`|0.55|にじみの強さ|
|`env.glow_hdr_threshold`|1.0|これより明るい所だけ発光|
|`set_glow_level` の表|0, .5, .8, .6, .3|にじみの広がり方（右ほど大きくぼける）|

炸裂の背後に赤黒い煤の影（impact/slashの形を黒赤で、抜きの層）を追加して赤黒さを出している。

既知の点：岩はゲーム内の大きさ（幅264px）では小さく見えることがある。実機Safariは未確認。
