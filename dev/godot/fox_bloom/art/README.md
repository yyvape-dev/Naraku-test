# 火の水面・花・花弁の専用素材

モチーフはユーザー指定（2026-10-15）。百鬼狐火の既存連番 `dev/cardart/fox_ult_seq/{08,20,36}.webp` を実見し、赤い火の水面、咲いた花、舞う花弁を参照した。既存連番そのものは切り抜いて流用せず、今回の立体開花用の原画を生成した。

- `petal_source.png`: GPT Image生成、1254×1254透過、幅広と細く巻いた2種類の花弁。元 `/workspace/generated_images/exec-d2660e44-c6e8-44a7-8120-84572f442f12.png` を保持してコピー。指示 `../prompts/petals.txt`。
- `petal_wide.png`: 上記の矩形(0,0,740,1254)。`petal_curl.png`: 矩形(760,0,1254,1254)。機械的に独立素材へ分けたもの。3D曲面メッシュへ貼るための素材で、完成した花の画像ではない。
- `water_source.png`: GPT Image生成、1254×1254、暗い赤の液体と不規則な反射。元 `/workspace/generated_images/exec-73d680d9-2a2a-465c-9559-205f784753fc.png` を保持してコピー。指示 `../prompts/water.txt`。3D水面上でUV移流・変形し、縁と透明度を処理する。

今回の主役・水面は専用生成素材。Jettelly・Kenneyは前の試作に残すが、新しい開花候補では使用しない。花弁と水の材質が主役で、煙に面積を使わない構成にしたため。外部商用ゲームの素材は使用していない。
