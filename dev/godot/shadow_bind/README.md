# 影縫い（ユーザー呼称：影しばり）青紫の試作

ユーザー添付の `blue_purple_vfx_keyframes_transparent_png.zip` 5枚を使用。原本はart/に無変更で保存。新規画像生成・外部素材の追加なし。

## 仕様と構成

- `fox_bind`：半径95、15ダメージ、命中は使用0.16秒後、鈍足4.5秒、装填8秒。爆心拡大4回で半径231.93359375、直径463.8671875。これらを変えず、見た目のみ置換する。
- 0〜0.16秒：細い影が立ち上がる予兆。0.10〜0.56秒：影の帯が増えて絡む。0.30〜1.02秒：収束した帯が内部を流れ、締まる。0.72〜1.32秒：横へほどける。1.04〜1.80秒：粒状に崩れて散る。絵のピークは命中より後。
- 5枚の役割はstart/build/converge/peak/dissipateという添付の名前と図像を確認して構成。原画の入れ替えだけで動かさず、`flow.gdshader`の上向きの移流ノイズ・高さで変化するねじれ・下からの出現・ノイズ消失を通して帯の中身を動かす。素材全体の回転はしない。
- 足元は不規則な影の濃淡と短い青紫の縁。空中は原画の暗部を残す通常合成＋明るい芯だけのHDR/Glow＋32個の控えめなGPU粒子。過剰な白の加算を避ける。
- 原本1254×1254。alpha>24の主形状は四辺から最低約60px内側、四辺の極薄いalphaは最大1/255。原本の切り詰め・再生成はせず、512論理サイズの制作画面へ余白を含めて配置。出力の四辺alpha最大値はatlas.jsonに記録。
- アンカー：原本(627,1020)をGodot論理(256,365)へ。床と空中を同じ位置へ描画。表示枠幅=半径×3.4、枠の中に透明余白を含む。通常323、最大788.57421875論理px。ゲームの戦場幅は360論理pxで、最大時に画面の外へ広がるのは範囲に伴う画面クリップ。
- 最大時の粗さを減らすため1024×1024で実描画し、空中512px/床192pxへ縮小。広い範囲では空中層を最大65%まで薄くし、敵の輪郭を透かす。最大サイズで原画本来の細部をすべて読めるわけではない。

## 再出力

```sh
DISPLAY=:97 sh dev/godot/shadow_bind/bake.sh
python3 dev/tools/embed.py dev/naraku_src.html index.html dev/assets
```

Godot 4.6.3、gl_compatibility、Xorg dummy＋Mesa llvmpipeで制作。X11ディスプレイは外部で準備する。bake.shはGodotをインストールしない。

各層を2回（透明の通常合成・黒背景のHDR/Glow）描画し、54コマ×30fps、1.8秒にする。HDRは光の回だけ有効。全Spriteのmodulateに頼らずシェーダー内のopacity/gainを使う。粒子は固定seed617・fixed_fps30・interpolate=false。

pack.pyで通常合成のpremultipliedと光RGBを正しく合成し、straight alphaの共有WebPアトラス2枚へ。1レイヤ9列×6行。フレーム毎のImage/Canvas生成なし。サイズ・復号メモリはatlas.json。

## 組み込みと確認

- 通常ゲームは従来のまま。`?shadowfx=godot`で試作、`?shadowfx=legacy`で従来。
- 比較：`dev/mock/shadow_bind_demo.html`。再生・停止・1/2/1/4速度・時間指定・床/空中の表示・最大範囲を操作できる。固定した敵と戦場を使用。
- 使用時に予兆を開始し、最初の命中では二重再生しない。二重詠唱の追撃では命中に合わせて0.16秒時点から再生。素材未読込時は従来演出。床は敵の後ろ、空中は敵の前・味方の後ろ。
- 命中・ダメージ・鈍足・装填・乱数は従来。絵だけが1.8秒で消えても敵の鈍足は続く。`dev/tests/shadow_bind.py`で通常/最大範囲・3シードの戦闘一致、命中・鈍足・追撃・片付け・フォールバックを確認。
- 見た目の採用はユーザー確認待ち。実機Safariは未確認。
