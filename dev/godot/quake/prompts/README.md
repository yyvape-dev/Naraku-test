# 大地割り：画像生成用プロンプト

目的はNarakuの重厚な既存アートに合う原画を先に作り、Godotで時間変化を設計すること。線・円・多角形だけの試作はデザイン基準にしない。

## 生成順

1. `01_slash.txt`：主斬撃。最初にこれを生成し、質感・配色を確認する。
2. `02_impact.txt`：命中の破裂。採用した主斬撃をスタイル参照にする。
3. `03_rock.txt`：石片。主斬撃と命中の絵を参照し、光の色を合わせる。
4. `04_dust.txt`：砂煙。同じ照明・画風で作る。

全素材は背景透過PNG。画像生成ツールでは `transparent_background: true` を指定。プロンプトだけで透明になると想定しない。元画像はPNGのまま保管し、Godotへ読み込む。PNGへの変換だけでは背景は消えない。

1024×1024を基準に生成。サービスが別の解像度を返した場合は、実寸を確認して取り込む。画像に文字・枠・人物・背景・完成カードを含めない。斬撃と命中は一枚につき一つの原画、石片も一つ。複数素材のシートを一度に生成しない。

## Godotで作る時間変化（仮設計）

- 0〜0.05秒：主斬撃を先端から露出。全体を一様に拡大して出さない。
- 0.03〜0.10秒：命中の破裂。白い芯は短く、周囲に金・暗赤の層を残す。
- 0.06〜0.35秒：石片を大小・速度・回転の違いを付けて飛ばす。岩の絵を粒子として使い、均一な多角形にしない。
- 0.10〜0.65秒：低い砂煙。ゆっくり広がり、薄くなる。敵の姿を覆わない。
- 亀裂は床レイヤ、石片・主斬撃は空中レイヤ。細かな揺れ・輪郭光・歪みはコード／シェーダーで調整。

この時刻は見た目の設計であり、ゲーム側の0.16秒後の命中を変更しない。素材生成後に静止画を小さな戦場へ重ねて評価し、採用した素材だけ動かす。コマ数は品質ではなく出力の滑らかさとして最後に決める。

## 一括作業

プロンプト作成→画像生成→確認→Godot導入→連番出力は同じ会話で続けて実行可能。ただし画像生成の結果は揺らぐので、最初の斬撃を見ずに残りを確定しない。独立した生成はまとめて依頼できるが、絵を確認して選び直す工程は省かない。

ChatGPT内でこの作業を進める場合は、この会話で利用可能な画像生成ツールを使う。別のGPTや別チャットへプロンプトを自動送信する仕組みとは異なる。
