# 狐火乱舞：ユーザー原画5枚＋Godot発光・GPU粒子（試作 2026-10-16）

状態：**試作・ユーザー確認待ち。ゲームへの組み込みはまだ。** 確認ページ：`dev/mock/foxfire_preview.html`。

- 対象：`fox_fire`（ユズナミキ「狐火乱舞」、target、半径72、ダメージ55、装填5秒）。ダメージ・範囲・時刻は変えない。
- 原画：ユーザー提供 `dev/cardart/foxfire_src/vfx_frame_01〜05.png`（1536×1536透過、中央1200×1200に収まる）。光の柱→開き始め→満開→最大→散る。
- ユーザー指定のモチーフ：紫・薄いピンク・火・墨絵のような黒。

## 作り方

- 36コマ・**30fps＝1.2秒**（装填5秒なので次の発動と重ならない）。床192px・空中320pxの6×6アトラス。アンカー(0.5, 0.655)、表示幅＝半径×3.4。
- 原画の花の芯と光の柱の根元は5枚とも同じ位置（y≈1130/1536、実測）。その点を回転・拡大の軸にしている（`PIVOT_Y`）。
- つなぎ方：前の絵は外側からノイズで焼け落ち、次の絵は中心から咲き広がる（`fox_art.gdshader` の burn／dissolve）。1枚目は上から下へ光が落ちる（ywipe）。全体はゆっくり回転・拡大して1つの動きにまとめる。予定表は `KEYS`。
- 原画は2回描く：通常合成（墨の黒を含む本来の色）と、加算の写し（`ART_LIGHT`＝0.26。発光の種）。
- 足したもの：墨の滲み（床・`ink_stain.gdshader`）、墨しぶき（抜きの粒子）、狐火の揺らめき・花びら2回・着弾の火花（光の粒子）、床の紫の光だまり。
- 焼き：`sh dev/godot/foxfire/bake.sh`（Godot 4.4.1、`--fixed-fps 30`）。出力 `out/foxfire_floor.webp`（約76KB）・`out/foxfire_air.webp`（約1.0MB）、展開後 約20MB。

## 途中で分かったこと（事実）

- **Godot 4のcanvasシェーダーで `texture(TEXTURE,UV)` を読んで COLOR を上書きすると、modulate／self_modulate が捨てられる。** `vec4 tex=COLOR;` を使う。これに気づくまで加算の写しを弱めても白飛びが減らなかった（白画素 144,076→24,188）。
- スクリプトに構文エラーがあるとGodotは終了せず止まり続ける。bake.sh に `timeout 900` を付けた。

## 調整のつまみ（`foxfire.gd` 冒頭）

|つまみ|今の値|効き方|
|---|---|---|
|`ART_LIGHT`|0.26|原画の発光の強さ。上げると明るく白っぽくなる|
|`LIGHT_GAIN`|1.06|光全体（粒子含む）の明るさ|
|`env.glow_intensity`|0.45|にじみの強さ|
